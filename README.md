## 📖 Miniguia de Estudo

### 🔹 Resumo Estruturado

Cibersegurança é o conjunto de práticas e tecnologias utilizadas para proteger sistemas, redes e dados contra acessos não autorizados e ataques digitais.

Os três pilares principais são:
- Confidencialidade → proteger informações
- Integridade → garantir que dados não sejam alterados
- Disponibilidade → manter sistemas acessíveis
